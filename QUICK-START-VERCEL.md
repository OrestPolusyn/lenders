## 🚀 Швидкий Deploy:

### **1. ✅ Code на GitHub**

```
✅ DONE! https://github.com/OrestPolusyn/lenders
```

### **2. Vercel Setup (3 хв)**

```
https://vercel.com/signup
→ Continue with GitHub
→ Import "OrestPolusyn/lenders"
→ Environment Variables:
   PUBLIC_WORDPRESS_URL=https://wp.leanders.markupers.com.ua
   PUBLIC_WORDPRESS_API_URL=https://wp.leanders.markupers.com.ua/wp-json/wp/v2
→ Deploy
```

### **3. Done! (2 хв build)**

```
✅ Site live: https://lenders-xxx.vercel.app
✅ SSR працює
✅ Instant WordPress updates
```
