# Інструкція по деплою

## Проблема з правами доступу

При завантаженні файлів на хостинг можуть виникати помилки з правами доступу (Permissions). За замовчуванням файли мають права 644, але деякі хостинги вимагають 755.

## Рішення

### Варіант 1: Використання npm скрипту (Рекомендовано)

Перед деплоєм виконайте:

```bash
npm run build:production
```

Ця команда:
1. Очищує попередній білд (`clean`)
2. Створює новий білд (`astro build`)
3. Автоматично встановлює права 755 на всі файли в `dist/`

### Варіант 2: Ручна зміна прав після білду

Після звичайного білду виконайте:

```bash
npm run fix-permissions
```

Або використовуйте bash скрипт:

```bash
./fix-permissions.sh
```

### Варіант 3: Зміна прав через SSH на хостингу

Після завантаження файлів на хостинг виконайте через SSH:

```bash
# Перейдіть в директорію з файлами
cd /path/to/your/website

# Встановіть права 755 на директорії
find . -type d -exec chmod 755 {} \;

# Встановіть права 644 на файли
find . -type f -exec chmod 644 {} \;
```

### Варіант 4: Через FTP клієнт

Якщо використовуєте FileZilla або інший FTP клієнт:

1. Виділіть всі файли/папки
2. Правою кнопкою миші → "File permissions" або "Права доступу"
3. Встановіть:
   - Для папок: 755 (rwxr-xr-x)
   - Для файлів: 644 (rw-r--r--)

## Автоматизація для CI/CD

Якщо використовуєте GitHub Actions або інший CI/CD:

```yaml
- name: Build and fix permissions
  run: |
    npm run build:production
```

## Пояснення прав доступу

- **644** (rw-r--r--): Власник може читати/писати, інші тільки читати
- **755** (rwxr-xr-x): Власник може все, інші можуть читати/виконувати
  
Для статичних сайтів:
- **Файли** (HTML, CSS, JS, зображення): 644 достатньо
- **Директорії**: завжди 755 (щоб веб-сервер міг їх читати)
